# DellLogicasPython - Manual de Execucao

## Descricao
Colecao de exercicios de logica de programacao em Python, incluindo integracao com Databricks SQL.

## Arquivos
- `Colab_Notebooks/Conexao_Colab_x_Databricks_Sql_connect.ipynb` - Conexao Google Colab com Databricks SQL

## Como Executar
1. Abrir o notebook desejado
2. Para o notebook de conexao Colab x Databricks:
   - Configurar as credenciais do Databricks
   - Executar as celulas de conexao
   - Testar queries SQL
3. Para exercicios de logica: executar as celulas em ordem
